# 생활꿀팁 YouTube Shorts

이 자동화는 이 폴더 안의 Codex CLI, 파일 우편함, Windows 작업 스케줄러만 사용합니다. Codex CLI는 이미 설치된 `D:\Tools\Codex`를 사용합니다. 예약 실행 중 Codex 데스크톱의 Scheduled 작업을 따로 띄우지 않으며, 일이 있을 때만 Codex 세션을 순서대로 실행합니다.
예약 작업은 `pythonw.exe`로 실행하고, 감시기와 렌더러가 실행하는 Codex·FFmpeg 등의 자식 프로세스에는 Windows 콘솔 창을 만들지 않는 옵션을 적용합니다. 실행 결과와 오류는 기존 로그에 기록됩니다.

## 매일 실행

신규 업로드는 오전·오후 모두 `status.containsSyntheticMedia=true`를 설정해 YouTube의 AI 콘텐츠 라벨을 적용합니다. 이미 업로드한 영상은 변경하지 않습니다.

- Windows 작업 스케줄러가 로그인할 때 파일 감시기를 시작하고, 매일 03:00과 15:00(한국 시간)에 각각 오전·오후 회차의 요청을 만듭니다. 업로드 마감은 각각 06:30과 18:30입니다.
- 메인 작성, 독립 검수, 시각 자료 제작, 최종 감사 단계를 별도 Codex CLI 실행으로 처리합니다. 단계 사이의 전달 내용은 `work/mailbox/runs/`와 `work/daily/`의 파일로 남습니다.
- 모든 확인이 통과하면 서로 다른 영상 두 편을 전용 YouTube 채널에 비공개로 올려 07:00과 19:00에 공개되도록 예약합니다. 각 회차의 마감을 넘기면 해당 회차만 건너뜁니다.
- 최종 결과(예약 성공, 건너뜀, 실패)는 `appleap385@gmail.com`에서 게재 결과 수신 메일 `aaz0919@naver.com`으로 발송합니다. 처음 한 번 `.\configure_email.ps1`을 실행해 Gmail 앱 비밀번호를 숨김 입력하고 테스트 메일을 확인해야 합니다. 비밀번호는 현재 Windows 계정에서만 복호화되는 DPAPI 형식으로 `state/`에 저장됩니다.
- PC가 03:00 또는 15:00에 꺼져 있거나 절전 중이거나 Windows 사용자 세션이 로그인되어 있지 않아 시작하지 못한 경우에는 해당 회차를 건너뛰며 보충하지 않습니다. 일시적인 통신·서비스 오류는 아래 복구 규칙으로 재시도합니다. 인증 취소, 품질 검수 실패, ImageGen 실패 등은 자동 재생성으로 우회하지 않습니다.
- Windows 사용자 계정은 로그인 상태로 두어야 하지만 화면은 `Win+L`로 잠가도 됩니다. PC는 켜져 있고 절전·최대 절전 상태가 아니며 인터넷에 연결되어야 합니다. 재부팅 후에는 Windows에 다시 로그인해야 감시기가 시작됩니다.
- Codex CLI는 단계가 실행되는 동안만 프로세스로 뜹니다. 감시기는 로그인 상태에서 가벼운 파일 확인만 수행합니다. Codex 데스크톱 앱의 창을 계속 열어둘 필요는 없습니다. CLI 로그인과 사용 한도는 필요합니다.

## 오류 재시도와 중단 복구

- 회차별로 최초 실행 포함 최대 3회 시도합니다. 일시 오류 뒤 1분, 다음 오류 뒤 3분을 기다리며 06:30/18:30 이후 해당 회차의 새 업로드를 시작하지 않습니다. 단계 제한시간도 남은 준비 시간 안으로 줄입니다.
- Windows 큐 작업은 인터넷이 잠깐 끊겨도 요청을 남길 수 있습니다. 감시기는 오류 종료 시 1분 간격으로 최대 3회 다시 시작하도록 등록합니다.
- 승인된 단계와 검증된 영상은 재사용합니다. 이미지 생성 호출 전에 시도 기록을 저장하므로 완료 여부가 불분명한 이미지 생성을 다시 호출하지 않습니다.
- 업로드 세션은 무시되는 `work/daily/YYYY-MM-DD/upload_session.json`에 보관합니다. 재시작 시 서버가 확정한 수신 위치를 조회해 이어 보내며, 파일·채널·예약 조건이 바뀌면 새 업로드로 대체하지 않습니다. 세션 파일에는 비공개 업로드 URL이 있으므로 공유하거나 커밋하지 않습니다.
- `upload.json` 성공 영수증을 실패 보고보다 우선합니다. 업로드 후 문자 출력 오류가 성공을 덮지 않도록 UTF-8 실행과 ASCII-safe 결과 출력을 사용합니다. 메일 발송도 최대 3회 시도합니다.
- 세션이 만료됐거나 완료 여부를 확인할 수 없으면 중복 방지를 위해 멈춥니다. 이때 `upload.json`/`upload_session.json`을 삭제해 재실행하지 말고 먼저 YouTube의 기존 영상을 대조해야 합니다.

## 계절 우선 주제 선정

한국 계절에 맞는 생활 정보를 먼저 검색합니다. 봄은 3~5월, 여름은 6~8월, 가을은 9~11월, 겨울은 12~2월로 봅니다. 현재 계절에 맞고 신뢰할 수 있는 출처 두 곳 이상이 뒷받침하며 시청자의 행동을 바꿀 만큼 유용한 주제를 우선 구성합니다. 그런 주제가 없을 때는 계절과 무관한 생활 팁으로 전환하고 대체 사유를 기록합니다. 계절에 억지로 맞추거나 근거를 만들어내지 않으며, 검수 세션에서도 이 선택을 다시 확인합니다.

대본에는 흔히 하는 방법과 그보다 나은 구체적 판단, 그 차이가 중요한 이유를 기록합니다. 과일을 냉장고에 넣거나 옷을 접어 보관하라는 식의 당연한 조언만으로는 검수를 통과하지 않습니다. 같은 분야가 연속되어도 실제로 유용하고 이전 내용과 다르면 채택할 수 있습니다.

연속된 설명인 `spoken_script`를 먼저 쓰고, 의미와 행동 단위에 맞춰 장면을 나눕니다. 장면 수는 네 개로 고정하지 않으며 전체 영상은 55초 이내입니다. 장면별 `visual_action`에는 대상·상태·행동을 명시합니다. 검수자는 처음 보는 시청자의 입장에서 내용을 다시 설명하고, 모든 장면 사이의 실제 연결 문구를 근거로 검사합니다. 중요한 조건을 설명란으로만 넘기지 않습니다.

글이 길면 줄바꿈과 읽을 수 있는 범위의 글자 크기(제목 36px 이상, 본문 30px 이상)를 자동 조정합니다. 그래도 맞지 않거나 흐름이 어색하면 이미지 제작 전에 대본·자막을 다듬거나 장면을 늘려 최대 두 차례 수정하고 독립 재검수합니다. 문장 뒷부분을 잘라내지 않습니다. 수정 후에도 사실·의미·가독성이 확보되지 않을 때만 해당 회차를 보류합니다. 이미지 격자와 음성 구간, 최종 검수 화면도 실제 장면 수에 맞춰 생성합니다.

모든 영상은 새 한국어 대본과 새 ImageGen 장면으로 만듭니다. ImageGen은 회차별 한 번, 정기 작업 기준 하루 최대 두 번 사용합니다. 한도 초과나 생성 실패 때 다른 이미지 API, 내려받은 사진, 코드 그림으로 대신하지 않고 해당 회차를 건너뜁니다. Gemini API를 사용하지 않습니다. 내레이션은 `edge-tts` Python 클라이언트로 Microsoft의 온라인 한국어 TTS 서비스를 호출하고, 렌더링은 720x1280, 15fps, FFmpeg 한 스레드로 제한합니다.

## 현재 설정

이 PC에는 채널 ID와 OAuth 토큰, 이메일 알림이 설정되어 있습니다. 작업 등록 스크립트는 기존 03:00 작업과 감시기에 15:00 오후 작업을 추가합니다. 오전 산출물·원장은 기존 `YYYY-MM-DD` 이름을 유지하고 오후는 `YYYY-MM-DD-pm`으로 구분합니다. 같은 날짜의 오전 영상도 오후 대본의 중복 검사에 포함합니다.

## 최초 설정 또는 복구

새 PC에서는 아래 채널 ID와 OAuth 설정을 끝내기 전에는 작업을 등록하지 않습니다.

1. PowerShell에서 `youtube_life_tips` 폴더로 이동해 `.\setup_codex.ps1`을 실행합니다. 기존 `D:\Tools\Codex`의 CLI 경로와 ChatGPT 로그인 상태만 확인하며 프로젝트 안에 CLI를 설치하지 않습니다.
2. `config.local.example.json`을 `state/config.local.json`으로 복사하고 생활꿀팁 전용 YouTube 채널 ID를 입력합니다. PIM 채널 ID는 쓰지 않습니다.
3. 생활꿀팁 채널을 관리하는 Google 계정의 OAuth 데스크톱 클라이언트 JSON을 `state/google_oauth_client.json`에 복사하고, 해당 Google 계정으로 OAuth 테스트 사용자 등록 및 `youtube.upload`, `youtube.readonly` 권한 설정을 완료합니다.
4. 이 폴더에서 `python authorize_youtube.py`를 실행하고 브라우저에서 해당 계정을 인증합니다. 출력된 채널 ID가 `state/config.local.json`의 ID와 정확히 같은지 확인합니다. 자격 증명과 토큰은 `state/` 아래에만 두며 Git에 올리지 않습니다.
5. Python 3, `ffmpeg`, `ffprobe`, 기존 `work/vendor` Edge TTS 및 Pillow가 준비되어 있는지 확인합니다.
6. 등록 전 점검: `python codex_mailbox.py doctor --require-youtube`
7. 점검이 통과하면 PowerShell에서 `.\register_tasks.ps1`을 실행합니다. 감시기와 03:00·15:00 작업이 등록됩니다. 해제할 때는 `.\unregister_tasks.ps1`을 실행합니다.

작업 등록 스크립트는 모든 사전 점검이 통과하지 않으면 작업을 하나도 등록하지 않습니다. Windows 시간대가 `Korea Standard Time`인지도 확인합니다. 작업 결과는 `work/mailbox/outbox/YYYY-MM-DD.json`, 감시 로그는 `work/mailbox/logs/watcher.log`, 이메일 오류는 `work/mailbox/logs/email.log`에서 확인할 수 있습니다. 이메일 설정은 YouTube OAuth 설정 후 `.\configure_email.ps1`을 실행해 완료합니다. Google 계정 비밀번호가 아니라 Google 앱 비밀번호를 입력하며, 입력값은 화면에 표시되지 않습니다.

## 제작·저작권 원칙

- 웹 검색은 사실 확인과 주제 조사에만 사용하고, 출처 문장이나 사진·영상·음성은 복사하지 않습니다. 출처 링크는 설명란에 기록하며 영상 화면에는 표시하지 않습니다.
- 참고 영상은 일반적인 편집 리듬만 참고할 수 있습니다. 프레임, 썸네일, 문장, 음성, 장면 구성은 가져오거나 재현하지 않습니다.
- 의료 진단·치료, 법률·금융 조언, 위험한 화학 혼합, 전기·가스 수리 등 위험한 주제는 자동 게시하지 않습니다.
- 생성 영상, OAuth 정보, 매일 작업 산출물은 커밋하거나 푸시하지 않습니다.
