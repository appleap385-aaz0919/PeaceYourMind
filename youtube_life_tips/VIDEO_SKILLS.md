## 이 프로젝트에서 우선 적용할 규칙

1. **범위:** 이 문서는 위 스킬의 원문 기본값보다 우선합니다. 설치·갱신 대상은 이 저장소의 `.agents/skills/`입니다. 전역 설치 옵션, 사용자 홈의 스킬·플러그인 등록, 전역 심볼릭 링크를 사용하지 않습니다. 새 런타임 의존성과 시제품은 `youtube_life_tips` 안의 별도 디렉터리에 둡니다. 갱신은 설치 기록의 저장소·경로를 확인하고 명시적인 프로젝트 설치 경로와 커밋을 지정합니다.
2. **실행 범위:** 스킬 설치는 예약 제작기의 렌더러 교체가 아닙니다. Remotion·HyperFrames를 선택한 제작·시제품 작업에서 해당 스킬을 읽습니다. 기존 ImageGen 경로의 실패를 숨기기 위한 자동 대체로 사용하지 않습니다. 예약 제작에 연결하려면 렌더 어댑터와 최종 검수 호환성을 먼저 구현·검증합니다.
3. **내용:** 소재 선정과 사실 검증은 `EDITORIAL_BRIEF.md`, 한국어 대본은 루트 `AGENTS.md`와 프로젝트 `humanize-korean`을 따릅니다. 구조 설명은 검증한 상태·좌표·동작 순서를 장면 명세로 확정한 뒤 코드로 표현합니다. 도형의 정확성이나 렌더 성공을 실제 팁의 효과 증거로 취급하지 않습니다.
4. **출력:** 생활꿀팁 공용 최종 영상은 720×1280, 15fps, 65~90초입니다. 기존 Edge TTS와 로컬 한글 글꼴을 사용합니다. 새 제작기에서도 전체 내레이션, 자막, 핵심 동작 전후 프레임, 실제 MP4의 길이·음성을 검수합니다. TikTok 전달은 기존 `save_tiktok_copy`와 `tiktok_uploads/YYYY-MM-DD/` 규칙을 따릅니다. 출처는 내부에 보존하고 YouTube 설명에 참고자료를 자동 첨부하지 않습니다.
5. **서비스:** 기존에 허용된 ImageGen·Edge TTS와 사용자 보유·허가 자산을 사용합니다. 업스트림의 ElevenLabs·HeyGen 추천은 이 프로젝트의 기본 공급자를 바꾸지 않습니다. 새 유료 생성·클라우드 렌더·계정 연결·외부 공개는 사용자의 명시적인 요청이 있는 작업에서만 수행합니다. 스킬 사용 비콘(`hyperframes events`), 피드백 전송, 사용자 프로젝트를 담은 원격 공유는 실행하지 않습니다. 런타임 도입 시 해당 버전의 일반 텔레메트리 설정도 확인합니다.
6. **작업 완료:** 사용자가 MP4 제작·게시를 요청한 작업과 기존 예약 작업은 이미 정해진 제작·검수·게시 권한에 따라 진행합니다. 업스트림의 미리보기 승인 기본값 때문에 확인을 다시 요청하지 않습니다. 렌더 성공 후에도 기존 독립 최종 검수와 채널·예약 확인을 생략하지 않습니다.

7. **미리보기 서버:** 필요한 경우 `--no-open`으로 실행하고, 사용자가 요청할 때만 브라우저를 엽니다. 샘플 제작·검수·저장이 끝나면 이번 작업에서 시작한 서버를 종료합니다. 종료 전 PID·명령줄·실행 경로를 대조해 이 프로젝트의 해당 프로세스임을 확인합니다. 포트 번호만으로 프로세스를 일괄 종료하거나 다른 프로젝트의 서버를 종료하지 않습니다.

## 검토 결과와 도입 순서

이번 오전의 봉제·서랍 그림처럼 연결 구조가 중요한 장면은 재생성할 때마다 형태가 달라질 수 있습니다. Remotion으로 홈·돌출부·실의 이동 경로를 명시하고 같은 상태를 반복 렌더하는 접근을 우선 검토할 만합니다. HyperFrames는 설명용 도형·자막·전환을 HTML로 구성하는 보조 선택지입니다. 이는 공식 문서의 기능을 이 프로젝트 문제에 적용한 판단이며, 실제 제작 시간이나 검수 통과율 개선을 아직 측정한 결과는 아닙니다.

최초 검토 단계에서는 스킬 파일과 참조 문서만 설치했습니다. npm 런타임 설치, 계정 연결, 예약 작업 교체, 새 영상 제작·업로드는 이번 검토에서 수행하지 않았습니다. 실제 도입 시 구조 설명 한 장면을 먼저 렌더해 원본 명세와 대조하고, 통과한 경로에 기존 음성·자막·최종 검수를 연결합니다. Remotion 런타임의 상업 이용 조건은 [공식 라이선스 안내](https://www.remotion.dev/docs/license)를 확인합니다. HyperFrames의 로컬 프레임워크는 Apache-2.0이며 클라우드·Pro 기능은 별도입니다.

검토한 공식 자료: [Remotion Agent Skills](https://www.remotion.dev/docs/ai/skills), [Remotion 스킬 원본](https://github.com/remotion-dev/skills/tree/1af7e69a2a613437d46095924057970a6a7df40d), [HyperFrames 원본과 실행 안내](https://github.com/heygen-com/hyperframes/tree/651de1d948b0f619001e3705cba98fa415baf0dd).
